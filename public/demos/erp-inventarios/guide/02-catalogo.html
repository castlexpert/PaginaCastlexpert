Catálogo de artículos

Cada artículo tiene un código interno y un código de etiqueta para pistola o cámara (EAN-13, Code 128, QR y demás simbologías usadas en Costa Rica). Si no hay etiqueta de fábrica, el sistema genera una.

Explicación de campos

Campo / controlQué esCómo usarlo
Código internoObligatorioCódigo propio del artículo (ej. ART-001).Úselo en reportes, CMMS y movimientos.
NombreObligatorioDescripción operativa.Ej. Filtro de aceite hidráulico.
Unidad (UND)OpcionalUnidad de medida.UND, KG, LT, CJ…
Stock mínimoOpcionalNivel de alerta.Referencia para reabastecer.
Generar etiqueta del sistema / Usar etiqueta original / de fábricaOrigen del código de escaneo.Con “Generar”, el sistema crea INV-<código> en Code 128. Con “original”, escriba el código impreso por el fabricante.
Código de etiquetaOpcionalLo que lee la pistola o la cámara. Vacío = se genera.El formato (EAN-13, Code 128, QR…) se detecta solo.
Registrar artículoGuarda el artículo.Muestra Guardando... mientras procesa.
Buscar por código interno, etiqueta o nombre...Filtro de la tabla.Escriba parte del código o del nombre.
