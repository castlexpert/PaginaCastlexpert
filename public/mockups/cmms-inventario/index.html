API 1 · Artículos hacia el CMMS

El ERP (o un job) envía o actualiza el catálogo y existencias en el módulo de inventario del CMMS. No se crean a mano si la fuente es Externa.

Dirección: ERP → CMMS

Cuándo: alta/cambio de SKU, ajuste de stock, sync programado

POST /api/inventario/erp/articulos Authorization: Bearer {token_tenant} { "origen": "ERP", "articulos": [ { "sku": "FIL-001", "codigoExterno": "ERP-FIL-001", "nombre": "Filtro 20x20", "tipo": "REPUESTO", "unidad": "UND", "stock": 2, "minimo": 5, "almacen": "Principal" } ] }

API 2 · Salidas hacia el ERP

Cuando el técnico confirma materiales usados en la OT, el CMMS reporta cada línea como salida de inventario para que el ERP descuente el stock.

Dirección: CMMS → ERP

Cuándo: al confirmar uso (no al cerrar la OT, salvo que el parámetro lo exija)

POST {erpBaseUrl}/inventario/salidas X-Tenant: {empresa} { "origen": "CMMS", "ot": "OT-2026-0027", "activo": "ACT-00015", "tecnico": "TecnicoJuan", "lineas": [ { "sku": "FIL-001", "codigoExterno": "ERP-FIL-001", "cantidad": 1, "unidad": "UND", "motivo": "CONSUMO_MANTENIMIENTO" } ] }
